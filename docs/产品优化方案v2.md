# SnapSort 产品优化方案（v2.0）

> 历史规划文档：记录 v2.0 阶段的设计依据，不代表 v3.4.0 当前目录结构或完成状态。当前信息请以根目录 README、CHANGELOG 和 DEVBOOK 为准。

> 目标：把当前「脚本工具感」的界面，升级为一款 Apple 风格、结构清晰、功能完整的桌面级素材分类软件，并为后续 Windows 打包做好准备。

---

## 一、产品定位

**SnapSort 2.0 = 本地 AI 驱动的图片素材整理工作台**

核心价值：把杂乱的原始照片，通过本地 AI 一键整理成可管理、可复核、可导出、可协作的素材库。

---

## 二、UI/UX 设计方向：Apple 风格

### 视觉原则
1. **整体布局**：侧栏导航 + 主内容区，类似 macOS Finder / Photos / 备忘录。
2. **配色**：浅色为主，背景 `#F5F5F7`（Apple 灰白），卡片白色，强调色 `#0071E3`（Apple 蓝）。
3. **字体**：macOS 优先 `SF Pro Display` / `SF Pro Text`，中文回退 `PingFang SC` / `Hiragino Sans GB`。
4. **圆角**：窗口/按钮/卡片统一 8–12px 圆角，按钮使用圆角胶囊风格。
5. **间距**：留白充足，信息密度适中，不堆叠过多控件。
6. **图标**：使用 Unicode 符号或轻量图标（暂不引入图标库，减少打包依赖）。
7. **交互反馈**：
   - 按钮 hover 有轻微颜色变化
   - 操作成功/失败用右上角 Toast 提示
   - 分类进行中用顶部进度条 + 状态文案

### 页面结构

## 三、功能增强规划

### 1. 仪表盘（Dashboard）
- 今日/累计处理图片数量
- 各分类素材数量分布（小条形图/数字卡片）
- 最近 5 次分类任务概览
- 快速操作入口：选择素材文件夹、开始分类、打开输出目录

### 2. 自动分类（Auto Sort）
- 保留现有功能：选择输入/输出文件夹、模型选择、增量处理
- 新增：拖拽文件夹到窗口即可选择
- 新增：处理前预览待处理图片数量、格式、大小
- 新增：分类完成后显示分类结果分布
- 新增：低置信度图片进入「复核台」而非强制归类

### 3. 素材库（Gallery）
- 按分类文件夹展示缩略图
- 支持点击放大预览
- 支持单选/多选：删除、移动到其他分类、收藏、添加标签
- 快速搜索：按文件名、分类、标签、描述搜索

### 4. 复核台（Review）
- 展示 AI 低置信度或归入「其他」的图片
- 人工选择正确分类，一键修正
- 修正结果自动同步到输出文件夹，并更新历史记录

### 5. 历史记录（History）
- 每次分类任务记录：时间、输入/输出路径、模型、处理数量、结果分布
- 可点击某次任务，快速打开对应输出文件夹
- 支持清空历史

### 6. 设置（Settings）
- 分类配置：增删改分类、编辑关键词/提示词
- AI 模型选择：自动读取 Ollama 已安装模型
- 输出选项：是否生成 CSV 报告、是否保留原文件名、重复文件处理策略
- 界面：主题切换（浅色/深色，后续实现）
- 快捷键说明

### 7. 其他好用的小功能
- **收藏夹**：快速标记重点图片，生成「精选集」
- **重复图片检测**：基于文件哈希或感知哈希去重
- **批量重命名**：按分类+序号批量重命名
- **一键导出**：把分类结果打包成 ZIP 或导出 Excel 报告
- **实时日志**：保留，但默认折叠，需要时展开

## 五、 Windows 打包方案（优化后执行）

### 推荐方案：PyInstaller 单文件/单文件夹
1. 在 Windows 上安装 Python 3.11+、Ollama
2. 使用 PyInstaller 打包为 `SnapSort.exe`
3. 安装包包含：
   - 主程序
   - Python 运行时
   - tkinter / customtkinter 依赖
   - 配置文件模板
4. 用户环境要求：
   - Windows 10/11 64位
   - 安装 Ollama 并下载对应视觉模型（如 `llava:13b`）
   - 约 8GB 内存（运行 llava:13b 时）

### 备选方案
- **auto-py-to-exe**：图形化 PyInstaller 配置，适合初次打包。
- **nuitka**：编译为 C 扩展，启动更快，但打包更复杂。
- **Inno Setup**：制作安装向导，适合正式分发。
